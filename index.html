Why NashamaAIHub

Jordanian Roots. Collective Intelligence. Real Impact.

NashamaAIHub is a shared home for everyone shaping AI in Jordan and the wider region — students, researchers, developers, entrepreneurs, professionals, universities, businesses and public institutions. We are not a consultancy, a course catalogue or a news portal. We are an open ecosystem where people learn together, exchange knowledge, and turn ideas into practical solutions.

The name draws on Nashama — a Jordanian word for people of courage, generosity and integrity who show up for their community.

Problem statement

Residents often struggle to find clear, up-to-date answers about routine procedures, especially on mobile and in Arabic. This project explores whether an assistant grounded only in published official guidance can reduce confusion.

Intended beneficiaries

Residents using public services; frontline service staff.

Implementation

Build brief & scope clarification

The domain is NashamaAIHub.com, and GitHub is the intended code repository and publishing workflow. Before implementation, explicitly separate the public website from account management, user submissions, administrative workflows, and payment processing. Identify the hosting and supporting services required for each capability. Do not represent a visual prototype or static page as a working membership platform.

This file is a design prototype. Sign-in, forms, registration and support pathways are simulated and store nothing.

Capabilities and supporting services

CapabilityWhat it needsCandidate services (to be decided)
Public websiteStatic bilingual pages, CDN, HTTPS, custom domainGitHub repo + GitHub Actions → Azure Static Web Apps or GitHub Pages; DNS for NashamaAIHub.com
Accounts & sign-inAny-email sign-up, verification, reset, optional Google/Microsoft, consent recordsManaged identity service, e.g. Microsoft Entra External ID, Auth0 or Supabase Auth — never custom password storage
Submissions & member dataAPI, database, file uploads with scanning, visibility rulesServerless API (e.g. Azure Functions) + managed database (Azure SQL / PostgreSQL) + blob storage
Content publishingBilingual editing of events, resources, podcastsHeadless CMS or Markdown-in-GitHub with pull-request review
Admin workflowsReview queues, moderation, roles, audit logProtected admin app on the same API with role-based access
Events & emailRegistration, reminders, .ics invites, recordingsTransactional email service; webinar platform (e.g. Teams webinars); video host for recordings
NewsletterDouble opt-in, separate from accountsEmail-marketing service with unsubscribe and consent logs
PaymentsNot in first releaseHosted payment provider only after legal entity, banking and any charitable status are confirmed
Privacy & securityPolicies, consent, data rights, accessibilityAlign with Jordan's Personal Data Protection Law; WCAG 2.2 AA; secrets in GitHub environments, never in the repo
